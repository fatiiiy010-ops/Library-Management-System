# 📚 Library Management System

A simple beginner-friendly Library Management System built with Python.

## 📌 About

This is a console-based Library Management System.
It allows users to add books, display available books, search for books,
and remove books from the library.

## ✨ Features

- ➕ Add a book
- 📋 Display all books
- 🔍 Search for a book
- ❌ Remove a book
- ⚠️ Book not found handling
- 🔢 Menu input validation
- 🛡️ ValueError handling
- 🔄 Continuous menu using while loop
- 🚪 Exit option

## 🛠️ Concepts Used

- Variables
- Lists
- Nested lists
- Functions
- `for` loop
- `while` loop
- `if / elif / else`
- `return`
- Function calls
- `append()`
- `remove()`
- Boolean variables
- `try / except ValueError`
- Input validation
